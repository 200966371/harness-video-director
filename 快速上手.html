视频导演 ／ DeepSeek Harness 插件
怎么开始怎么修改和 Skill 的区别安装能力与数据

01 / 在原聊天开始

打开 Harness 的普通聊天，
把制作要求发给它。

这张网页是说明书。实际操作入口是 DeepSeek Harness 原来的聊天输入框。安装并重启后，就在任意聊天里交代目标；成片也会出现在这个聊天里。

  1. 01

    回到 Harness 聊天

    打开一个普通聊天。首次使用可点输入框旁的“＋ 技能”，选择 video-director。

  2. 02

    放素材、发要求

    把配音或录屏拖进输入框，再说明想做什么。只有文字时，也可以先做无声动画。

  3. 03

    看成片、直接反馈

    等待聊天中的视频作品卡。看完继续说“第二段字放大，配音别动”，就能接着修改。

没有素材？复制这一段到 Harness 聊天，试一次完整流程

请使用视频导演插件，做一个 10 秒的横屏无声动画，1920×1080，带中文字幕。内容是：把资料分成“待处理”“处理中”“已完成”三类。让文件卡片实际移动到对应分类里，文字清楚。自动安排镜头，完成后在本聊天给我可播放的视频。

这个例子不用准备录屏或配音，也不用购买声音服务。它会实际制作 MP4；耗时取决于模型响应、画面复杂度和电脑性能。

先把配音文件拖进同一个聊天，再发送这句话。想加固定标题或品牌名称时一起说。

已经有素材，直接拖进聊天

这是配音和录屏，帮我剪成教程。配音不要改，重点操作放大一点。

素材会复制到项目目录，原文件保留。已有附件无需再重复粘贴路径。

导演会按每个镜头自动安排动画、真实操作或混合画面，无需分别调用两项 Skill。也可用 /video-director 明确调用。只有文案时，当前插件不自带自动配音；要有旁白，请提供配音，或说明可以使用的配音工具。

02 / 看作品，再说怎么改

修改意见仍然留在同一个聊天里。

成片以作品卡出现在对话中。播放检查之后，可以直接说时间点或段落，也可以点击卡片上的镜头引用，把定位信息带回原输入框。

  1. 01

    播放与保存

    在作品卡看实际导出的视频，检查文字、动作、节奏和声音，再保存需要的版本。

  2. 02

    引用镜头并反馈

    选中镜头，补充具体修改意图和要保持的部分。导演据此修改相关源码与衔接。

  3. 03

    从当前进度继续

    卡片的“继续制作”回到原会话。重启后也可以说“继续刚才的视频”。

第 2 段像 PPT，让资料真的分到不同类别里。配音别动，其他内容保持。

每次计划和源码修改都会保存版本，旧视频保留。本版会修改局部源码后重新导出整片；原聊天“停止”可取消正在执行的渲染。作品卡的“未主观审片”需要通过实际观看和试听补足。

03 / 和直接用 Skill 的区别

制作方法沿用两项 Skill，
插件把保存、渲染和作品卡一起装好。

两者都由 Harness 当前的主模型接单，聊天用法很接近。Skill 可以包含说明和脚本，也能做出视频；插件把这两项 Skill 与固定的制作工具、运行依赖和聊天展示打包在一起。

你关心的事直接使用 Skill使用这个插件
开始制作加载 Skill，Agent 按说明调用当前环境已有的能力。统一由“视频导演”接手，后台使用两项 Skill，并提供安装好的本地渲染工具。
作品与版本文件、记录及续做方式取决于 Skill 和所在项目的实现。自动保存素材、分镜、源码、历史成片，并将项目与聊天关联。
播放与修改结果如何预览、下载和定位修改，由宿主与具体工作流决定。聊天内直接播放、拖动、保存；引用某个镜头，把修改定位填回同一输入框。
停止与恢复取决于实际使用的脚本和工具。原生“停止”取消本次渲染；继续时读取已保存的项目。尚未完成的渲染会重新执行。
画质与审美取决于模型、素材、镜头设计和输出设置。同样取决于这些因素。安装插件本身不会自动提高画质或让模型更聪明。

如果你自己的环境已经配好，直接用 Skill 也能完成制作。这个插件主要让其他人安装后少配置环境、少找项目文件，并且能在原聊天里持续修改作品。

04 / 安装一次

装进 Harness，沿用你当前的主模型。

打开 Harness 的「插件 → 添加插件」，复制下面这一整行链接粘贴到输入框，点击安装：

https://github.com/200966371/harness-video-director/releases/download/v0.1.0/lifei-harness-video-director-0.1.0.tgz

无需下载、解压或寻找本地路径。三个 Skill 已经包含在安装包中，不需要额外安装 Skill 或 Codex。

安装完成后点击「立即启用」并重启 Harness。确认已配置自己的模型，回到任意原有聊天，按上面的例子直接开始。

首次安装通常需要联网访问 GitHub 和 npm 安装源，以下载插件和渲染依赖。

首版验证环境为 macOS Apple Silicon、Harness 0.2.1-rc.2；其他系统及版本需单独验证。运行需 Node.js 24+，Harness 桌面版自带运行时。优先使用本机 Chrome/Chromium/Edge；未找到时下载 Chromium 并跨项目复用。

视频在本机渲染，不调用付费视频生成服务。插件不包含 API key、作者的个人素材或账号配置，沿用你当前的 Harness 主模型。

使用命令行安装
dsh plugin --profile desktop add https://github.com/200966371/harness-video-director/releases/download/v0.1.0/lifei-harness-video-director-0.1.0.tgz
从源码安装（开发者）
npm ci
dsh plugin --profile desktop add /绝对路径/video-director-plugin --ignore-scripts

先在源码目录执行 npm ci，再替换安装路径。完成后同样重启 Harness。

05 / 知道它现在能做到哪里

真实制作、保留版本，缺什么就说清楚。

这一版的能力

  • 输出真实 Remotion MP4：动画讲解、导入录屏制作教程、混合视频。
  • 支持导入一条主旁白，从 0 秒按原速、原音量装配；导出编码为 AAC，不保证压缩后字节与源文件相同。
  • 缺真实录屏时可继续其他部分，完整成片等待必要素材；不会画出虚假的软件成功结果。
  • 技术检查覆盖编码、尺寸、时长、帧率和音轨；完整观看与听感仍需实际审片。

自动操作任意软件录屏、购买配音／图片／音乐服务、自动发布均未内置。需要时使用当前会话已有工具，并遵守本次授权。

作品和项目存在哪里

默认数据目录：

~/.dsh/data/lifei-video-director

项目包含 project.json、assets/、sources/ 和 revisions/；聊天绑定保存在 sessions/。

插件升级与项目数据分开，当前不会自动清理历史视频。可在插件 config 中用 dataRoot 指定数据目录。

同一用户跨聊天继续时，可明确给出项目 ID。若重启前的任务没有完成记录，状态会显示中断，恢复后从真实保存进度继续。
